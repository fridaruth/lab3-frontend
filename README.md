# CV - Frontend

En webbplats för att visa och hantera arbetserfarenheter. Sidan hämtar data asynkront från en extern webbtjänst via Fetch-anrop.

Lösningen består av en flersidig applikation där det finns sidor för att visa listan över erfaranheter, lägga till nya samt en om-sida. 

---
# 🔗 **[Länk](https://lab2cv.netlify.app/)**

## 🛠 Teknik
* **Vite** - Build tool och dev-server.
* **SASS** - För styling.
* **JavaScript** - Fetch-anrop och DOM-hantering.
